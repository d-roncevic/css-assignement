# Travel Guide: Kenya, Albania & Croatia

A simple HTML and CSS webpage showcasing three fascinating destinations.

[Live Demo](https://d-roncevic.github.io/css-assignement/index.html)

## Features

- **Responsive Design**: Clean, modern layout built with HTML5 and CSS3
- **Three Destinations**: Explore Kenya, Albania, and Croatia
- **Static Content**: Pure HTML and CSS (no JavaScript)

## Destinations

### Kenya
Discover East Africa's wildlife, landscapes, and vibrant culture.

### Albania
Experience the Adriatic beauty and rich history of this Balkan gem.

### Croatia
Explore Mediterranean coastlines and ancient European architecture.
